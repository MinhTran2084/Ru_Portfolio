# Ru | Art Portfolio

Portfolio website for Ru, an art student. Built with Vite + React and deployed
to GitHub Pages automatically on every push to `main`.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints in the terminal.

## Add a project

Each project is a folder in `src/projects/` with an `info.json` and its images.
See [PROJECT_NOTES.md](PROJECT_NOTES.md#adding-a-project) for the exact steps.
